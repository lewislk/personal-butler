# 《私人管家APP》极简现代化UI完整设计方案
## 基础产品规范（统一极简风格底层标准）
### 1. 设计定位
极简干净、低干扰、轻量化私密工具向，无花哨动效、无渐变堆砌，主打浅白+低饱和辅助色，信息层级清晰，兼顾日常记录与隐私安全感，适配你的5大核心功能+全局待办聚合需求。
### 2. 全局设计规范
#### 色彩系统（极简低饱和）
- 主色：柔和雾霾蓝 #4A86E8（按钮、选中态、重点标识）
- 文字主色：#1D1D1F（正文、标题）
- 文字次要：#757575（辅助说明、标签）
- 分割/背景灰：#F5F7FA（页面底色、卡片底色）
- 危险色：#E55757（删除、过期提醒）
- 成功色：#48BB78（完成事项、纪念日倒计时）
- 密码模块专属深色卡片：#2A2A38（强化私密感）
#### 字体规范（无衬线极简）
- 标题：18/20px 粗体
- 模块小标题：16px 常规
- 正文内容：14px 常规
- 小字备注：12px 浅灰
#### 组件统一规则
1. 圆角统一：卡片12px、按钮8px、输入框6px
2. 阴影：仅轻微下阴影（0 2px 8px rgba(0,0,0,0.06)，不厚重）
3. 间距：统一4/8/16/24px四档间距，杜绝杂乱留白
4. 图标：线性细线条图标，无填充粗图标，统一24px尺寸
5. 动效：仅极简淡入淡出、轻微滑动，无弹跳、闪烁特效

# 页面完整UI结构（底部三Tab：主页 / 通知 / 我的）
## Tab1：主页（核心首页，你的核心需求落地页）
页面从上至下分层布局，垂直流式排布，层级：顶部状态栏→APP标题区→全局聚合【待办模块】→五大核心功能快捷入口区→空白留白
### 区域1：顶部标题栏（固定顶部）
- 左侧：APP名称「私人管家」20px粗体
- 右侧：2个极简线性图标（搜索图标 + 本地备份图标）
- 背景纯白，底部一条1px浅灰分割线区分下方内容

### 区域2：全局聚合待办模块（首页核心模块，卡片式）
卡片底色#F5F7FA，圆角12px，内边距16px
1. 卡片头部（左右分栏）
   - 左：标题「今日待办」+ 小字「聚合日程/纪念日/烹饪计划所有未完成事项」
   - 右：文字按钮「查看全部」（点击跳转独立待办列表页）
2. 待办列表（最多展示3条，超出折叠，底部显示「还有X项待办」）
   单条待办行布局：
   - 左侧圆形单选框（未完成空心、完成填充主色打勾）
   - 中间文字：事项名称 + 浅灰小字标注来源（日程/纪念日/烹饪）
   - 右侧：时间标签（如「今天18:00」「3天后」）
3. 底部操作：浅色小字按钮「新建待办」，一键快速新增通用待办

> 逻辑联动：所有模块内带提醒、未完成的任务自动汇总到此，统一查看，不用切换各个功能页。

### 区域3：五大核心能力子能力入口（网格快捷区）
2行3列网格布局，仅展示5个功能，最后一格留白美化，每个入口为独立小卡片
统一卡片样式：纯白底色、轻微阴影、居中布局
单格内部结构：
1. 顶部线性图标（对应功能专属图标）
2. 中间功能名称（14px）
3. 底部浅灰小字标签（一句话定位）
清单：
1. 日程管理｜图标日历｜标签：计划/提醒
2. 纪念日管理｜图标爱心日历｜标签：生日/倒计时
3. 密码记录｜图标锁｜标签：私密账号存储
4. 美食记录｜图标餐盘｜标签：探店打卡相册
5. 烹饪管理｜图标锅铲｜标签：自建菜谱

交互：点击任意卡片，直接进入对应功能独立页面。

### 页面底部：空白缓冲留白
无多余推荐、广告、资讯，纯极简留白，降低视觉压迫。

## Tab2：通知（第二底部切换页）
整体纯白极简，分为两大板块
1. 顶部标题「通知」，右侧「一键已读」文字按钮
2. 通知列表（时间倒序）
单条通知卡片：
- 左侧来源图标（日历/锁/美食/锅铲）
- 中间：通知标题+详情小字
- 右侧：通知时间
- 底部区分线
通知分类：日程提醒、纪念日倒计时、自定义烹饪计划提醒
无通知状态：居中极简插画+文字「暂无待通知事项」，干净无多余引导

## Tab3：我的（第三底部切换页）
垂直卡片式分层，极简无复杂头像装饰
1. 顶部私密安全卡片（核心，匹配密码模块隐私定位）
   - 标题：隐私安全设置
   - 功能项：应用锁（指纹/面容/数字密码）、数据本地备份、数据恢复、清除缓存
2. 功能设置列表（独立分割卡片）
   - 通用设置：提醒音量、深色模式切换、农历显示开关
3. 关于板块
   - 版本信息、使用帮助（本地静态说明，无在线客服弹窗）

# 五大子页面统一极简UI规范（点击首页入口进入）
所有子页面保持统一设计语言，结构标准化：
1. 顶部返回栏：返回箭头 + 页面标题
2. 主体：列表/卡片布局，统一留白
3. 右下角悬浮按钮：圆形「+」主色按钮，统一新增内容
4. 无多余弹窗、开屏广告、社区推荐

## 1. 日程管理页面UI
- 顶部切换：日视图 / 月视图 简约分段标签
- 列表：时间轴排布日程条目
- 每条日程：时间条色块 + 事项标题 + 备注小字
- 底部悬浮+：新建日程

## 2. 纪念日管理页面UI
- 顶部展示：距离最近纪念日倒计时卡片（绿色文字突出天数）
- 下方列表：按时间近远排序，每条标注公历/农历
- 悬浮+：新建纪念日

## 3. 密码记录页面UI（差异化深色卡片，强化私密）
整体页面白底，单条密码卡片采用深色#2A2A38深色模式
- 每条卡片：平台名称、账号，密码默认圆点隐藏，眼睛图标点击明文展示
- 右侧复制双按钮（复制账号/复制密码）
- 顶部分类下拉筛选：社交/办公/金融/自定义
- 悬浮+：新增账号密码

## 4. 美食记录页面UI
- 卡片图文布局：图片居左，文字居右
- 内容：店名/菜品、星级评分、就餐标签、简短评价
- 顶部标签筛选栏：火锅/奶茶/中餐等
- 悬浮+：新增美食打卡

## 5. 烹饪管理页面UI
- 菜谱卡片：小图封面、菜名、难度+烹饪时长标签
- 点击卡片进入详情页：分层展示食材清单、分步烹饪步骤、小贴士
- 悬浮+：新建自建菜谱

# 底部Tab导航栏（全局固定，极简设计）
整栏高度56px，纯白底色，顶部一条浅灰分割线
均分三栏，每栏结构：线性图标 + 下方小字
1. 主页：首页图标 + 文字「主页」（选中时主色蓝色，未选中灰色）
2. 通知：铃铛图标 + 文字「通知」
3. 我的：用户轮廓图标 + 文字「我的」
交互规则：当前页面Tab图标+文字同步变色，其余置灰，无夸张放大动效。

# 极简UI核心差异化亮点（区别市面上繁杂管家App）
1. **信息高度收敛**
所有待办统一聚合在首页顶部，不用跨页面查找提醒，解决多模块事务分散痛点；
2. **极低视觉负荷**
无渐变、无大面积色块、无动效轰炸，大量留白，适合长时间记录、查看密码等私密操作；
3. **隐私视觉区分**
密码模块采用深色卡片，视觉上强化私密属性，给用户安全感；
4. **结构统一标准化**
首页、子页面、个人中心全部一套卡片、圆角、间距规范，开发成本低，视觉统一；
5. **无冗余商业化元素**
完全剔除广告、商城、社区、推荐，纯粹工具型极简管家，契合个人私密记录定位。

# 补充交互细节（极简风配套逻辑）
1. 所有弹窗采用底部弹出极简浮层，无全屏遮挡弹窗；
2. 删除操作增加二次轻确认弹窗，不强制阻断；
3. 待办勾选完成后，条目轻微淡化置灰，不直接删除，可随时恢复；
4. 所有数据默认本地存储，无强制登录、强制联网，贴合私密定位；
5. 深色模式一键切换，整套UI同步适配暗色极简版本。
