# 私人管家 · UI 原型图

根据 `docs/UI_DEMO.md` 极简现代化 UI 设计方案绘制的高保真 HTML 原型图。

## 查看方式

直接在浏览器中打开：

```bash
open ui-prototype/index.html
```

## 已包含页面（共 8 屏，iPhone 尺寸 375×812）

### 底部 Tab 主页面

1. **Tab1 · 主页**
   - 顶部纯净标题栏，无右上角按钮
   - 待办卡片：**「今日待办 / 近期待办」分段切换**，右侧显示当前面板条目数
   - 待办列表在卡片内**独立滚动**，无论多少条都不会顶下功能网格
   - 五大 + 笔记，共 **6 个应用**，2 × 3 网格
   - 待办卡片与功能网格纵向 **3 : 2 比例锁定**

2. **Tab2 · 全部应用**
   - 顶部提示条：「前 6 个将展示在主页」
   - 右上「排序 / 完成」切换按钮
   - 完整应用列表（当前 10 个）+ 拖拽把手 + 序号徽章
   - **前 6 项蓝色徽章 = 首页展示；7+ 灰色徽章 = 首页折叠**
   - 中间虚线分隔线「— 首页折叠 —」实时跟随第 6 与第 7 之间
   - HTML5 原生拖拽，松手自动重编号 + 更新徽章颜色 + 移动分隔线

3. **Tab3 · 我的**
   - **隐私安全设置**：应用锁 / 数据备份 / 数据恢复 / 清除缓存
   - **关于**：版本信息
   - 已剔除装饰性 emoji、左侧色条、通用设置模块、使用帮助等冗余项

### 五大核心功能子页面（顶部返回栏 + 右下角悬浮 + 按钮）

4. **日程管理** — 日/月视图分段 + 时间轴列表
5. **纪念日** — 顶部倒计时 Hero 卡 + 「每年重复 / 累计天数」**分段切换**
   - 每年重复：绿点 + 「还有 X 天」（如：妈妈生日 · 还有 3 天）
   - 累计天数：蓝点 + 「第 X 天」（如：入职纪念 · 第 1590 天）
6. **密码记录** — 参考纪念日 Hero 卡的**浅色渐变卡片**，三种低饱和色调分类
   - 社交（浅雾霾蓝） / 金融（浅薰衣草） / 办公（浅薄荷）
   - 卡片带同色系低饱和边框 + 极淡有色阴影
   - 私密感由**锁徽章 + 密码圆点遮蔽 + 眼睛按钮**承担
7. **美食记录** — 顶部标签栏 + 图文左右卡片 + 星级评价
8. **烹饪管理** — 顶部分类 + 双列菜谱卡片 + 难度/时长标签

## 交互能力（原型可点击试用）

| 位置 | 交互 |
|---|---|
| 主页待办卡片头部 | 点击「今日待办 / 近期待办」切换面板 |
| 任意待办条目 | 点击整条切换完成状态（勾选/取消） |
| 全部应用列表 | 鼠标拖拽任意行，重排后自动重编号 + 徽章更新 + 分隔线跟随 |
| 全部应用右上角 | 点击「排序 / 完成」切换编辑态文案（主色 ↔ 危险色） |
| 纪念日下方分段 | 点击「每年重复 / 累计天数」切换两组不同语义的纪念日 |

## 设计遵循

- 主色：柔和雾霾蓝 `#4A86E8`
- 文字：`#1D1D1F` / 次要 `#757575`
- 页底/卡底灰：`#F5F7FA`
- 危险色 `#E55757` / 成功色 `#48BB78`
- 圆角：卡片 12px、按钮 8px、输入框 6px
- 阴影：`0 2px 8px rgba(0,0,0,0.06)`
- 间距 4 / 8 / 16 / 24 四档
- 线性 24px 图标（内联 SVG，无外部依赖）
- 分段切换控件（待办 / 纪念日通用同款）：浅灰底 pill，选中白底 + 轻阴影 + 加粗

## 结构说明

单文件 `index.html`，所有样式、SVG 图标、交互 JS 全部内联，无第三方依赖（仅 Google Fonts 字体，可离线降级）。方便日后复用到 iOS SwiftUI 时对照实现。
