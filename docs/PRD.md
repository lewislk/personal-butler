## 1. 产品目标

### 1.1 核心理念

一款**极简、干净、低干扰**的个人管家 App，主打以下四个原则：

1. **信息高度收敛** — 所有待办统一聚合在首页，不需要跨模块查找
2. **极低视觉负荷** — 无渐变堆砌、无动效轰炸、大量留白
3. **纯本地私密** — 数据默认本地存储，无强制登录、无联网上报
4. **无商业化元素** — 零广告、零推荐、零社区，纯工具属性

### 1.2 与市面同类产品的差异化

| 常见管家 App | 私人管家 |
|---|---|
| 多模块跨页找提醒 | 首页聚合所有待办 |
| 花哨渐变 + 大色块 | 浅白底 + 低饱和辅助色 |
| 通知/广告/社区堆砌 | 三 Tab 极简，零商业化 |
| 强制账号 + 云同步 | 本地存储，无需登录 |

## 2. 全局设计规范

### 2.1 色彩系统

| 用途 | 色值 |
|---|---|
| 主色 | `#4A86E8` 柔和雾霾蓝 |
| 文字主色 | `#1D1D1F` |
| 文字次要 | `#757575` |
| 页面/卡片底色 | `#F5F7FA` |
| 分割线 | `#ECEEF2` |
| 危险色 | `#E55757` |
| 成功色 | `#48BB78` |
| 密码卡片渐变 · 社交（蓝） | `#F4F7FE → #E9EEFB` |
| 密码卡片渐变 · 金融（紫） | `#F6F3FC → #ECE5F7` |
| 密码卡片渐变 · 办公（绿） | `#F0FBF5 → #E1F1E8` |

### 2.2 字体规范

- 页面标题：20px 粗体
- 模块标题：16px 常规/粗体
- 正文内容：14px 常规
- 小字备注：11–12px 浅灰

### 2.3 组件统一规则

- **圆角**：卡片 12px / 按钮 8px / 输入框 6px / 头像 pill 16px
- **阴影**：`0 2px 8px rgba(0,0,0,0.06)` 极轻
- **间距**：4 / 8 / 16 / 24 四档
- **图标**：线性细线条 SVG，主图 24px，卡内小图 16–18px
- **动效**：仅淡入淡出、150ms 分段切换过渡，无弹跳/闪烁
- **分段切换控件**：浅灰底 pill，选中项白底 + 加粗 + 极轻阴影（应用于待办、纪念日等）

### 2.4 页面结构约定

- 底部 Tab 栏：56px 高，纯白底 + 顶部 1px 分割线
- 顶部标题栏：14/20px 内边距，纯白底 + 底部 1px 分割线
- 子页面：返回箭头 + 页面标题 + 右下角圆形悬浮 `+` 按钮
- 弹窗：一律底部浮层，无全屏遮罩
- 删除操作：二次轻确认，不强制阻断

## 5. Tab1 · 主页

### 5.1 布局结构

```
┌────────────────────────┐
│ 标题栏「私人管家」        │
├────────────────────────┤
│ 待办卡片（占 3/5 高度）  │
│  · 分段切换：今日 / 近期  │
│  · 待办列表（内部滚动）   │
├────────────────────────┤
│ 应用网格 2×3（占 2/5）   │
└────────────────────────┘
                    Tab 栏
```

### 5.2 待办卡片

#### 5.2.1 视觉

- 卡片底色 `#F5F7FA`，12px 圆角，16px 内边距
- 卡片头部左侧为分段切换 pill：`[今日待办] [近期待办]`
- 卡片头部右侧显示当前面板条目数（如「6 项」）

#### 5.2.2 数据来源

聚合所有其他应用中带**提醒/日期**的未完成事项：

- 日程管理中的当日/近日日程
- 纪念日（每年重复类型）的邻近提醒
- 烹饪管理中标注了「今日烹饪」计划的菜品
- 未来其他应用产生的提醒（预留扩展）

#### 5.2.3 「今日待办」逻辑

- 展示**当前自然日**（0:00–23:59）内触发的所有事项
- 已完成事项显示在列表下方，条目文字变淡灰 + 中划线
- 不显示跨日事项

#### 5.2.4 「近期待办」逻辑

- 展示**未来 7 天**（不含今天以外的过去日）的所有事项
- 每条右侧显示相对时间（如「明天 07:00」「周四 · 3天后」「下周日 15:00」）
- 按时间正序排列

#### 5.2.5 交互

| 元素 | 动作 | 反馈 |
|---|---|---|
| 分段切换 pill | 点击 | 切换面板，右侧条目数刷新 |
| 单条待办 | 点击整行 | 切换完成状态（勾选圆点填充 → 主色，条目文字淡化 + 中划线） |
| 已完成条目 | 再次点击 | 恢复为未完成 |
| 待办列表 | 上下滑动 | 卡片内部独立滚动，**不影响下方应用网格位置** |

#### 5.2.6 待办条目结构

```
[○/●]  事项名                        [时间标签]
       来源 · 日程/纪念日/烹饪
```

- 圆形勾选框：未完成空心 1.5px 灰边 / 完成为主色实心 + 白色对勾
- 事项名：14px 主色文字
- 来源：12px 浅灰
- 时间标签：12px 浅灰药丸，紧急（临期）为危险色

### 5.3 应用网格

#### 5.3.1 布局

- 2 行 × 3 列，共 6 格
- 展示「全部应用」列表中**排序前 6 位**的应用
- 卡片：纯白底 + 12px 圆角 + 极轻阴影 + 1px 浅灰边

#### 5.3.2 卡片结构

```
       [图标]
       应用名称
       小字标签
```

- 顶部线性图标 32×32
- 应用名 14px 主色
- 定位标签 11px 浅灰

#### 5.3.3 交互

- 点击进入对应应用子页面
- 顺序**跟随「全部应用」页的排序自动同步**（前 6 项）

### 5.4 屏占比约束

**待办卡片 : 应用网格 = 3 : 2**（垂直方向），锁定不变。待办再多也在卡片内部滚动，不挤压应用网格位置。

### 8.3 纪念日

#### 8.3.1 结构

```
[返回] 纪念日
─────────────────
Hero 卡片（浅绿渐变）
最近的纪念日
妈妈生日 🎂
   3 天后
公历 · 7月23日 · 农历 六月十九
─────────────────
[每年重复][累计天数]   ← 分段控件
─────────────────
（当前面板对应的列表）
                          [+]
```

#### 8.3.2 两种纪念日类型

| 类型 | 语义 | 徽章文案 | 场景举例 |
|---|---|---|---|
| **每年重复** | 每年一次，倒计时提醒 | 「还有 X 天」 | 生日、结婚周年、传统节日 |
| **累计天数** | 从起始日累加，展示已过天数 | 「第 X 天」 | 入职、恋爱、戒烟、开始学习某技能 |

#### 8.3.3 视觉区分

- 每年重复：**绿点** `.anni-type-dot.green` + 绿色/橙色徽章
- 累计天数：**蓝点** `.anni-type-dot.blue` + 蓝色徽章
- 临近 7 天内的每年重复纪念日：徽章变橙色 `warn` 状态

#### 8.3.4 数据模型

```swift
enum AnniversaryType {
    case yearly(nextDate: Date)    // 每年重复
    case cumulative(startDate: Date) // 累计天数
}

struct Anniversary {
    var id: UUID
    var name: String
    var date: Date                 // 公历日期（原始存储）
    var isLunar: Bool              // 是否按农历生成下一次
    var type: AnniversaryType
    var reminderDaysBefore: Int?
}
```

#### 8.3.5 农历支持

- 用 `Calendar(identifier: .chinese)` 计算下一次到达日
- 显示时若 `isLunar` 为 true，标签为「农历 · 九月初八」

- 私密感通过**锁徽章** + **密码字段圆点遮蔽** + **眼睛/复制按钮**共同承担，不靠色差硬撑

| 卡片本体 | 点击进入编辑详情页 |

#### 8.4.4 安全

- 密码字段**加密存储在 iOS Keychain**
- 应用锁开启时，进入本页需二次校验（面容/密码）
- 剪贴板复制后 **60 秒自动清除**（可配置）
- 数据备份文件对密码字段单独加密

### 8.7 笔记

#### 8.7.1 定位

- 用于记录日常灵感、摘录、简短随笔

## 9. 待办聚合规则（关键跨模块逻辑）

主页「今日/近期待办」的数据由以下模块贡献：

| 来源模块 | 触发条件 | 展示文案 |
|---|---|---|
| 日程管理 | 有 `reminderMinutesBefore` 且未完成的日程 | 事项名 + `来源 · 日程` |
| 纪念日 | 每年重复类型，且距离下次到达 ≤ 提醒天数 | 纪念日名 + `来源 · 纪念日` |
| 烹饪管理 | 用户在菜谱详情页点了「加入今日烹饪计划」 | 菜名 + `来源 · 烹饪` |

### 9.1 完成状态

- 用户在主页勾选完成时，需**回写到源模块**（如日程勾选完成 = 该日程 `isCompleted = true`）
- 反向：源模块本身完成事项后，主页待办列表自动移入已完成态

### 9.2 时间分组

- **今日**：`Date` 落在今天 0:00–23:59
- **近期**：未来 7 个自然日内的所有事项（含今日）

## 10. 非功能性需求

### 10.1 存储

- 使用 **SwiftData / Core Data**，数据完全落本地
- **密码字段单独入 iOS Keychain**
- 图片文件放在 `Documents/PersonalButler/media/` 目录，DB 内存路径引用

### 10.2 备份与恢复

- 备份产物：单个加密 `.pbbak` 文件（内含 DB + Keychain 密码密文 + 图片打包）
- 用户可导出到 iCloud Drive / 文件 App / AirDrop
- 恢复时二次校验，避免覆盖当前数据前先给用户备份提示

### 10.3 通知

- 使用 `UNUserNotificationCenter` 本地通知
- 首次进入需要提醒功能的模块时，请求通知权限
- 权限被拒绝时，模块内 UI 显示轻量提示条：「已关闭通知，功能仍可用但无提醒」

### 10.4 应用锁

- 支持面容 ID / Touch ID / 6 位数字密码
- 进入 App 时校验，从后台恢复超过 60 秒也需校验
- 密码模块单独二次校验

### 10.5 兼容与性能

- iOS 17 及以上（SwiftUI 5 特性可用）
- 冷启动 < 800ms
- 主页首屏渲染 < 300ms
- 列表数据超过 500 条时使用 lazy 加载

### 10.6 深色模式

- **首期不做**完整深色模式适配（避免过度承诺）
- 后续版本再评估

### 10.7 国际化

- 首期仅中文
- 数据模型不硬编码文案，便于日后拓展

### 10.8 无障碍

- 所有可点击元素支持 VoiceOver 描述
- 图标按钮均需 `accessibilityLabel`

## 12. 明确不做（负面清单）

以下功能**明确排除在产品范围外**，避免需求膨胀：

| 不做 | 原因 |
|---|---|
| 账号系统 / 登录注册 | 违背「纯本地私密」定位 |
| 云同步 / 多端同步 | 同上 |
| 社区 / 分享 / 好友 | 违背「工具型极简」定位 |
| 广告 / 内容推荐 | 违背「零商业化」原则 |
| 内购 / VIP | 首期免费，未来若付费，仅一次性买断制 |
| AI 助手 / 智能推荐 | 增加复杂度，与极简定位冲突 |
| 通知中心（App 内） | 已由主页待办聚合承担 |
| 使用帮助 / FAQ | 产品足够简单，需要说明书就是设计失败 |
